# Release review

The release contains authored RTL and a testbench, sanitized project scripts, constraint provenance, a results summary, and selected project images. The file review covered hidden files and verified local checksums for all 38 EDA reports listed in the [report index](../reports/README.md).

The GitHub repository is intended for private review while ownership and redistribution permissions are unresolved. Twenty original EDA reports are included for private review. The other 18 original reports and mapped-design images are kept local. The release also excludes licensed technology inputs, generated implementation files, and internal publication drafts. See the [rights policy](../RIGHTS_AND_PUBLICATION.md) and [image selection](IMAGE_SELECTION.md).

The completed implementation was reviewed using its existing artifacts. The ASIC flow was not rerun.
